# 三程序双向通讯示例

三个独立程序分别模拟订单、计费和审计，各自通过 mod 连接独立临时 Hub。示例演示应用选择的请求、回复和跨程序转交；名称和正文仅为测试材料。

```powershell
npm run demo:three
```

只需 Node 22。runner 启动自己的 Hub 与三个外部程序，核对真实消息与结果，再停止所拥有的进程；默认 `npm test` 包含这条链路。

订单规则、计费逻辑、审计处理和调用次序属于这些外部程序。Hub 只按通讯身份、权限、订阅和目标转交任意正文。读取和 ACK 不触发释放，释放由提供者明确决定。这些测试程序不会随正式 Hub 默认启动。
