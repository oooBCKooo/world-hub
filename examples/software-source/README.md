# Static software source example

This open index distributes the same independent Python text-statistics module used by the cross-language example. The artifact includes its MIT license and bridge adapter. Retrieving it does not install dependencies or execute the module.

In **Software sources**, inspect `https://raw.githubusercontent.com/oooBCKooo/world-hub/main/examples/software-source/index.json`, review the entry and its digest, then fetch it. Use the resulting module directory as a replacement in **Creator workspace**. If your network uses a DNS proxy with virtual/private addresses, explicitly select the trusted-private network option for this source.

For offline exploration, inspect `offline-index.json` in this directory. It references the identical artifact by a bounded relative path. Source unavailability does not prevent previously verified cached modules or installed packs from running.

The index is a distribution example, not publisher authentication or execution authorization. Review licenses, source code, permissions and the selected environment before running a derived pack. See the [open source format](../../docs/ecosystem/sources.md).
