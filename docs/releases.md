# 构建与分发

## 0.22.0

- 非交互 CLI 提供 84 项本机管理操作，包括模块、配置、数据、接线、启动计划、版本、卸载及外部桥接入；CLI、JavaScript 管理 SDK 和可选 MCP 共用公开 API 客户端及操作目录。
- MCP 管理默认关闭，通过工具权限和准确操作名分别授权；会执行解释器探测的检查/预览按写操作授权。附件状态与释放限本连接近期上传；写入结果过大也保留已应用或未知结果的诊断，不自动重试。
- 配置应用关联已有同成员组，保留业务组身份和作者接线基线。替换或停用配置清理无活跃引用且归属明确的辅助组，保留并行实例和局部重叠组。
- Skill、双语说明和发行清单同步更新。TUI 延后至 Hub 实际使用确认稳定后再考虑，本次不增加终端交互界面。

World Hub UI 独立发布为 `world-hub-ui@0.1.1`，包含配置组展示及切换体验修复。Hub 不携带界面；两者按各自包版本安装。

```powershell
npm run test:distribution
npm run test:npm
npm run build -- --output .artifacts/packages/world-hub-source
```

构建器按明确源码清单生成带摘要的独立 ZIP 和 manifest，包含无界面 Hub、CLI、SDK、模块工具、Skill／MCP 与可选社区后端。源包不捆绑第三方运行时；便携参考运行时单独审阅其许可证与摘要。

World Hub 不生成 ui.cmd，不携带管理页面、社区网页、Soft UI 模块、可视化演示包或截图。World Hub UI 有自己的 package、测试、构建与发行周期；不需要与 Hub 同时发布。

npm 实装验收包括陌生工作目录、隔离本地与全局安装、真实桥往返、管理 API 安全、正常停机及发行文件边界。版本声明、协议协商与制品摘要保持独立，不自动转换旧 UI 入口。
