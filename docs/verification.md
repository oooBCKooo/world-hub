# 验证范围

World Hub 的默认测试覆盖通信、SDK、管理 API、安全、持久化、请求／注入／大对象、多轮外部工作流以及源码分发。资源、社区、真实 npm 安装、可选语言和 MCP 另有显式套件。

无界面测试实际创建不含任何前端文件的发行目录，启动 Hub、连接两座枢纽桥收发、读取状态与资源 API，再正常关闭。npm 和 ZIP 验收检查没有页面、CSS、截图和浏览器脚本。

World Hub UI 单独测试渲染、语言、筛选、代理和交互。其真实 CLI 联调用 HTTP／WS 连接独立 Hub；关闭 UI 后 Hub 必须继续服务。界面测试不作为 Hub 核心测试的前提。

每次结论以实际运行日志与报告为准。静态检查、单元测试、真实 HTTP／WS 联调、浏览器操作和真人独立验收是不同证据。真人第三方独立开发与新手验收按用户决定保留待办。

`npm run test:cli` 验证共享管理客户端和非交互命令，包括独立 Hub 的审阅注册、启停、分组、私下交付外部桥凭据与真实通讯；`npm run test:agents` 检查 Skill 安装和真实 MCP stdio。两者都不自动接受审阅或重试结果未知的写入。环境检测会执行解释器探测，按写操作授权。`npm run test:resources` 包括配置重复切换、辅助组清理、既有业务组关联、并行实例和提交失败恢复。
