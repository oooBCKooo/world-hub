# 用 Launcher 安装、组合和接入独立程序

[English](launcher-deployment.en.md)

Launcher 提供可选的程序部署服务。模块仍拥有业务、状态、窗口和内部子进程，Hub 只处理模块桥通讯。作者应将可安装源码发行包与普通开发源码区别开；普通 `package.json` 项目不会被猜测为可运行模块。

在“我的模块”选择“导入本地模块”，使用“选择 ZIP…”或“选择文件夹…”，然后“检查并导入”。导入会验证发行声明和归档边界，不运行代码。没有合法声明的目录会报错，不会显示成功卡片。

要创建整合包，在模块卡片点击“新建组合”，或在工作台点击“新建整合包”。加入所需模块、选择版本与能力提供者、填写程序公开参数，然后审阅组合并“确认创建并导入”。随后在整合包卡片点击“启动”，审阅本次执行与依赖准备。无需写配置文件，最终组合必须有完整的能力接线；未完成的选择不会生成可执行包。

要直接使用本机 Hub，在模块卡片点击“接入本机 Hub”。先登记提供者，再登记依赖它的使用者，在表单选择能力提供者。所有协作程序登记完成后，打开“管理本机独立程序”，逐一审阅并启动。此路径直接部署独立程序，不生成整合包。程序使用各自的私人身份、权限和状态目录；停止一个程序不会停止共享 Hub 或其他程序。停止本机 Hub 会先取消正在准备或排队的独立程序启动，等待清理完成并停止其所拥有的程序，再停止 Hub；停止期间不能新增启动。

提供者的程序配置是每次启动时审阅的快照。新消费者需要提供者接受其身份时，应重新审阅并重启提供者。Hub 可以接收新的模块桥，但不会替业务程序修改授权或业务配置。Launcher 不接管由其他工具启动的未知进程，也不通过磁盘中的旧 PID 强制清理它们。

整合包、模块、模板以及下载制品按稳定项目 ID 归组。同一项目的多个版本、来源、目录或实例保留在卡片的选择器里。操作针对当前所选项；刷新或发现新版不会替换选择。原选项消失时需要重新选择。运行实例、业务状态和停止操作仍然独立；删除模块或模板卡片中的所选项只从库中隐藏那个版本目录，不删除磁盘源码。

## 作者部署声明

`module.json` 继续使用 `world-hub.module/v1`。可选 `deployment.json` 使用 `world-hub.deployment/v1`，其结构见 [Schema](deployment.schema.json) 和 [正式桌面模块](../../examples/soft-ui-modules/desktop/deployment.json)。它声明中英名称、主题默认值、桥槽发布/订阅默认值和公开参数字段。能力契约仍由模块作者决定，表单只依据声明装配。

运行配置 `world-hub.run/v1` 增加 `bindings`（已选定的精确能力边）和可选 `deployment.directory`（私有准备目录）。主题别名由部署桥默认值与实际接线映射；程序从 `peers` 与 `bindings` 解析协作主体，不写死实例名称。模块入口仍使用 `--runtime-config`，通过 `module-ready`、`module-health` 和 `stop` 协作生命周期。

`dependencies` 支持 `npm-lock` 配方，要求 `package.json`、完整 v3 `package-lock.json`、精确直接版本、官方 npm 注册表 URL 与 SHA-512 摘要。依赖下载与完整性核对发生在显式启动审阅后；不会执行模块或依赖的自定义安装钩子，不依赖用户的 npm 登录或全局 npm 配置。私有准备目录包含发行源码及依赖，启动前会核对保存的文件清单；源码、锁或安装结果发生变化都会要求重审或拒绝复用。

可选 `electron` 配方目前固定支持 Electron 44.7.1，使用其官方安装器和官方发行校验，要求 Node 22.12.0 以上。首次准备可能需要下载较大的桌面运行时，界面保持任务状态并允许取消。完整环境通过核对后可以复用。

Node 模块可以声明 `permissions.processes: "owned-children"`，用于受审阅的本机原生宿主。Windows 使用属于当前监督者的 Job，Linux 使用属于当前存活监督者的进程组，合作退出失败时退役所属树；其他平台提前拒绝此部署 profile。Linux 后代主动脱离进程组不在该 profile 的保证范围。这是生命周期所有权，不提供操作系统沙箱。原有 `processes: "none"` 模块保持兼容；已有容器隔离 profile 仍要求不声明子进程。

正式测试模块为 `world-hub-soft-ui-desktop-0.3.0.zip` 和 `world-hub-soft-ui-counter-0.3.0.zip`。桌面提供者与计数业务模块独立发行，业务经 Hub 返回界面；窗口和计数状态均不在 Hub 中执行。源码见 [examples/soft-ui-modules](../../examples/soft-ui-modules/README.md)。
