# 模块导入、接入与直接装配

[English](launcher-deployment.en.md) · [Launcher](launcher.md)

## 导入模块

在「模块库」选择作者提供的模块目录或 ZIP。程序至少带 `module.json`，可选 `deployment.json` 提供公开设置、主题别名和桥槽权限默认值。普通项目 ZIP、已安装运行时和整合包／模板不是当前模块格式；不通过删文件或忽略锁来猜测可运行内容。

导入只校验、取得并登记源码，不启动程序。不同版本集中在同一项目下选择；同一 ID 和版本出现不同摘要时需明确处理内容冲突。删除一个库版本不等于停止或删除已经接入的实例。

## 登记到一个全局 Hub

选择模块版本，创建独立实例，检查名称、解释器、公开参数、具体主题和桥槽的发布／订阅权限。作者没提供默认值时，按模块说明填写；Hub 不推测应用通道。相同模块可登记多次，实例之间使用独立身份和状态目录。

在启动审阅里核对当前源码与解释器，明确授权后运行。缺依赖或内容变更时先解决问题再检查，不自动改写作者源码。模块运行的业务与子进程职责由它自己的协议确定。

## 工作台直接保存

选择已接入实例，在工作台修改公开参数、主题、桥权限及所需能力提供者。能力绑定使用精确提供者实例和契约，不能把同名视为业务兼容。

审阅显示当前配置修订、内容变化和影响范围。保存作用于明确选中的实例；需要停止受影响实例时按审阅执行，其他实例继续运行。旧审阅不能覆盖并发的新修改。Hub 发行版本和模块版本不因一次调参变化。

工作台不再先生成整合包，也不套用模板；保存的是本机实例配置。凭据和业务数据不成为公开设置。

## 模块组和启动计划

组引用已有实例。两组引用相同实例时，共享同一配置和进程；不能把组启动理解为复制实例。启动计划可选择部分成员，精确调整顺序，配置前置关系。计划外成员可手动启动。

停止或修改共享成员前查看受影响的组和消费者。删除组保留实例；移除实例与清理数据是独立操作。恢复默认计划只改变当前草稿，再经审阅保存，保留当前成员集合。

## 软件源与选项变化

「下载」获取成功后模块加入本机模块库；获取与运行授权分开。来源不可用时显示真实原因和已有索引观察，只能使用后台已经验证的缓存，不沿用执行授权。

仍可用的原选项保持不变。失效时优先保留同一实例／目录／来源制品，否则选择同组可用项，并显示自动切换提示。不会自动下载、升级、启动或提交旧审阅。

自行管理的 Electron、服务和已有软件按[独立程序接入](external-programs.md)连接同一个 Hub；Launcher 不接管它们的窗口或未知进程。
