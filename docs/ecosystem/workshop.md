# 独立 Workshop 社区

Workshop 是可选的外部分发服务，提供账号、不可变作品版本、开放软件源、评论和改进提案。当前作品只有单模块与模块组：单模块发布独立程序，模块组分享成员源码、公开配置、接线与启动计划。上传程序不会在社区服务器执行。社区登录、下载与签名都不授予本机执行权限。

模块管理、工坊下载和模块组装配都在通信管理界面中进行，不再需要独立 Launcher。模块组的成员接入本机同一个 Hub，保留各自实例、版本和生命周期。它不携带或创建独立 Hub。旧整合包与模板不属于当前发布、下载或导入格式。

## 独立部署

```powershell
world-hub-workshop --config '<private-config.json>'
```

需要自己的私有配置、数据根和 HTTPS 代理。使用 `--initialize-admin <name> --password-stdin` 初始化管理账号，秘密从标准输入提供；不要放进进程参数或公开源码。帮助、停止与私有导出使用 `--help`、`--stop` 和 `--export`。默认 Hub 不启动社区。

现有官方公开入口：[World Hub Workshop](https://peros.cn/workshop/)。通信管理界面的工坊使用 `https://peros.cn/workshop/index.json`。社区网站也可直接下载 `artifact.json`，再在本机通信管理界面导入。网页只提供本机界面快捷链接，不向本机发送社区登录凭据，不直接调用本机管理接口。服务可用性和目录内容以实际在线响应为准。

若可信代理把来源域名解析到私网或虚拟地址，工坊会提示默认网络策略拒绝该地址。仅在确认来源和代理可信后勾选界面的私网选项再检索；该选择同时用于本次索引与制品下载，HTTPS 证书和摘要校验仍然执行。也可通过社区网页下载文件后本地导入。

## 发布和协作

作者使用符合[模块与模块组来源格式](sources.md)的 `artifact.json`。单模块含 `module.json`；模块组含 `module-group.json` 及引用的成员源码。网页预览只解释文件，服务器独立核对类型、清单、身份、版本、源码路径和摘要。制品 JSON 上限为 8 MiB；附带作品图片的完整发布请求上限为 16 MiB，Base64 和 JSON 编码也计入请求大小。

同类型和身份的作品在同一作品卡片中选择版本；精确版本及摘要才是下载目标。作品版本不可变，改进应发布新版本。评论按纯文本处理。提案绑定原制品摘要，不自动写作者源码；作者核对后自行采纳并发布。账号权限与公开软件源不代表程序已通过业务验收。

### 自动读取配置与发布审阅

发布页选择制品后，会把同一份 `artifact.json` 交给社区后端完整校验，再自动读取模块的 `module.json`、`deployment.json` 和模块组成员声明。显示标题默认取作者声明的对应语言名称，也可自行修改。切换语言或前往登录不会丢失当前页面内的制品、图片和草稿；刷新、关闭页面或主动清空草稿后会清除这些内存数据，密码不会保存在草稿中。

预览与作品详情共用配置展示：运行环境及平台、常驻／按需初始策略与空闲停止时间、安装依赖、提供和需要的能力契约、默认参数、指定提供者、主题和模块桥的收发范围。模块组还显示启动顺序、启用项、成员版本，以及成员的来源默认值和组内覆盖值。未声明策略时明确显示系统初始值；来源不会携带本机调用方授权。

详情的配置按所选精确版本的制品摘要读取，既有作品无需重新发布。npm 依赖来自实际清单与锁文件；Python 简单 requirements 声明可结构化展示，其他依赖文件会标明尚未解析，不据此推断版本或安装成功。此处只解释制品，不运行、安装或接线。

`POST /api/artifacts/preview` 接受 `{ "artifact": <完整制品> }`，要求当前社区会话、同源及 CSRF，沿用上传大小与速率限制，不保存制品；返回 `{ "configuration": ... }`。`GET /api/publications/<entryId>` 包含相同的 `configuration`，也可用 `GET /api/publications/<entryId>/configuration` 单独取得。投影包含精确 `sha256`，不能通过另传配置摘要覆盖制品中的声明。

### 选择历史版本

打开作品详情，在下载区选择需要的精确版本，然后核对该版本的平台、契约和摘要再下载。卡片默认展示最高语义版本，补发较旧版本不会把它当作最新版。单模块与模块组都按同一规则处理；模块组的配方版本和内部各成员模块版本分别记录。

发布新版不会自动隐藏、替换或删除已发布版本。所有公开版本保留各自的详情链接、原始制品和摘要，并同时进入软件源索引；通信界面的工坊也可选择相应版本。不存在于社区的历史版本需要作者另行上传，版本选择器不会生成或推测它们。社区不根据安装环境自动替换使用者选定的版本，也不承诺任意历史版本都适合当前环境。

历史版本保留原来的文件内容。若该版本没有 `deployment.json` 接入默认值，仍可下载源码，但使用者需要在本机提供接入配置，不能直接沿用最新版的默认值或假定它能自动适配新版环境。例如官方 `demo.source` 的 `1.0.0`、`1.0.1` 和 `1.0.2` 没有接入默认值，`1.0.3` 才提供；社区不会为旧版本补写文件并继续使用原版本号。

只有明确的下架操作才会把某个版本移出公开目录和索引。已下载的本机模块不因此删除或自动停止，原制品字节也不因发布新版本而改写。发布者应在作品说明中列明适用环境、已知问题及升级要求，让使用者根据自己的需求决定版本。

### 图标、封面与预览图

发布表单可选填作品图标、封面和最多 6 张预览图，并为图片填写简短说明。图标用于作品辨认，封面显示在目录卡片，预览图展示在作品详情中。未上传图片的作品仍可正常发布和下载，页面使用默认标识。

图片只接受静态 PNG、JPEG 或 WebP，服务器检查实际文件内容与声明类型是否一致。图标最大 512 KiB，封面及每张预览图最大 1 MiB，全部图片合计最大 5 MiB；每边尺寸为 1–4096 像素，最多 16,777,216 个像素。SVG、动画和外部图片地址不属于上传格式。图片说明最多 256 个字符，应描述使用者需要识别的界面或内容。

作者或管理员可在该精确版本的详情页展开“编辑作品图片”，添加、移除或替换图片。图片独立存放为社区展示数据，修改图片不会更改源码制品、版本号、发布者证据或制品摘要，也不会更新已安装程序。不同发布版本的图片分别维护；上传新版不会把另一个版本的图片自动迁移过去。

API 发布请求在原有字段之外可带 `presentation`；更新既有作品图片使用 `POST /api/publications/<entryId>/presentation`，同样要求会话、精确来源和 CSRF。结构为 `{ "presentation": { "icon": <image>, "cover": <image>, "screenshots": [<image>] } }`，其中新图片为 `{ "mimeType": "image/png", "base64": "<canonical Base64 bytes>", "alt": "界面说明" }`。更新时可用 `{ "sha256": "<该版本已有图片摘要>", "alt": "新说明" }` 保留已有图片；不能引用其他作品或该版本当前未采用的图片。省略的图片不再用于该版本展示，传空对象可清空全部图片。单独更新图片的请求上限为 8 MiB。

公开图片使用本站 `/workshop/media/<sha256>.<png|jpg|webp>` 地址，并按原始字节摘要校验。社区仅提供仍被公开作品引用的图片，下载器和 Hub 通信格式不需要解析图片。图片是作品说明，不代表代码安全、实际兼容或功能已经验收。

## 本地管理与安全

- 页面与 API 同源，管理操作要求会话和 CSRF。
- `GET /api/catalog` 支持搜索、`module`／`module-group` 类型、契约和分页。
- `GET /index.json` 提供公开模块与模块组来源；制品按精确版本和摘要取得。
- 下载组后，成员仍需在本机导入、配置和审阅；不会自动启动或替换已有运行实例。
- 上传、评论、提案和账号操作使用独立社区身份；不会发送本机管理凭据。
- 私人导出可能包含账号、会话和协作状态，不能作为公开模块上传。迁移前停服务并核对完整导出和目标文件权限。

公共发布者证据最大 256 KiB，签名与私钥边界见[信任说明](trust.md)。来源、评论、下载量和签名不能替代本机代码与权限审阅。服务只负责分发和协作，Hub 仍只负责通信。
