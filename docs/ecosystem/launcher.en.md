# Local module management

World Hub is headless and no longer serves `/manage`. Module, configuration, data and lifecycle operations remain available through local management APIs.

See [project separation](../specs/ui-separation.md), [management APIs](../specs/management.md), and [module resources](../specs/module-resources.md). Start World Hub UI separately with the actual Hub address when a graphical client is needed. Legacy Launcher pages and startup commands are not current entry points.
